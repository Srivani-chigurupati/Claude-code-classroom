# Reports

The nine submission reports are generated here by:

```bash
npm run dev -- airaamane simple-todo-app 1
npm run dev -- airaamane simple-todo-app 2
npm run dev -- airaamane simple-todo-app 3
```

Each run writes `airaamane_simple-todo-app_<pr>.json`, `.md` and `.html`.

This directory is currently empty of reports: generating them requires a live
ANTHROPIC_API_KEY, which was not available in the build environment.
